
# URL Shortener

Welcome to the **URL Shortener** project! This Node.js application allows you to quickly and easily shorten long URLs, making them easier to share and manage. Try it out at [URL Shortener](https://url-jwwf.onrender.com).


## Features

- **Fast and Easy**: Shorten URLs in seconds with a simple and intuitive interface.
- **Analytics**: Track the number of clicks on your shortened URLs.



## Installation

### Prerequisites
Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v14 or later)
- [npm](https://www.npmjs.com/)

Install my-project with npm

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/url-shortener.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd url-shortener
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```

### Running the Application

1. **Start the server:**
   ```bash
   node --watch index.js
   ```
2. **Access the application:**
   Open your browser and go to [http://localhost:8001](https://url-jwwf.onrender.com)
